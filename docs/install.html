Установка сервера

Сервер Lumen — один исполняемый файл с веб-интерфейсом внутри. Нужен компьютер или NAS, который включён, когда вы смотрите, и ffmpeg.

Docker (рекомендуется)

docker run -d --name lumen --restart unless-stopped \
  -p 8420:8420 \
  -v /путь/к/config:/config \
  -v /путь/к/медиатеке:/media \
  -e VAULT_MEDIA_ROOT=/media \
  ghcr.io/sidun-av/lumen-server:latest

Образ для linux/amd64 и linux/arm64, ffmpeg уже внутри.

Готовый файл

Скачайте архив для своей системы на странице выпусков (Linux x86-64 и ARM64, macOS Apple Silicon и Intel), установите ffmpeg и запустите:

VAULT_DATA_DIR=~/lumen/config VAULT_MEDIA_ROOT=~/lumen ./lumen-server

На macOS файл пока не подписан: перед первым запуском выполните xattr -d com.apple.quarantine lumen-server.

Первый запуск

  1. Откройте http://<адрес-компьютера>:8420 в браузере и создайте администратора.
  2. Разложите файлы по папкам внутри VAULT_MEDIA_ROOT:
    ПапкаЧто
    media/movies/фильмы, одна папка на фильм
    media/series/сериалы: Название/Season 01/…S01E01…
    media/music/музыка: Исполнитель/Альбом/
    media/books/ebooks/книги EPUB, FB2, PDF
    media/books/audiobooks/аудиокниги, одна папка на книгу
    media/books/manga/комиксы и манга CBZ
  3. Создайте профили для семьи. Детским профилям задайте возрастное ограничение.
  4. Установите приложение Lumen на iPhone, iPad или Mac и введите адрес сервера.

Основные настройки

VAULT_DATA_DIRбаза и настройки сервера
VAULT_MEDIA_ROOTкорень медиатеки
VAULT_LISTENадрес и порт, по умолчанию :8420
VAULT_PUBLIC_URLhttps-адрес сервера в интернете, если он есть
VAULT_TMDB_KEYключ The Movie Database для обложек и описаний (необязательно)

Для доступа из интернета используйте https через обратный прокси или VPN (например, Tailscale). Добавляйте в медиатеку только файлы, на которые у вас есть права.

Лицензии сторонних компонентов — в файле THIRD_PARTY_LICENSES.md в каждом архиве.

In English

The Lumen server is a single executable with the web UI built in. Run it with Docker (ghcr.io/sidun-av/lumen-server, linux/amd64 and arm64, ffmpeg included) or download a binary for Linux or macOS from the releases page and install ffmpeg. Open http://<host>:8420, create the administrator, put your files into media/movies/, media/series/, media/music/, media/books/ebooks/, media/books/audiobooks/ and media/books/manga/ under VAULT_MEDIA_ROOT, create profiles, then enter the server address in the Lumen app. Only add files you have the rights to.
