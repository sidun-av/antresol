Политика конфиденциальности приложения Antresol

Действует с 26 октября 2026 года.

Antresol — приложение для iPhone, iPad и Mac, которое показывает и воспроизводит вашу собственную медиатеку: фильмы, сериалы, музыку, книги, комиксы и аудиокниги. Они хранятся на сервере Antresol, который вы (или администратор вашей семьи) устанавливаете на своём компьютере или NAS. Разработчик приложения не предоставляет контент и не держит серверов, через которые проходят ваши данные.

Коротко

  • Разработчик не собирает никаких данных: нет аналитики, рекламы, отслеживания, сторонних SDK и отчётов о сбоях, отправляемых разработчику.
  • Приложение обменивается данными только с сервером, адрес которого вы ввели, и загружает обложки с общедоступных сайтов (см. ниже).
  • Данные входа хранятся в связке ключей (Keychain) вашего устройства.
  • Сохранённые для просмотра без сети файлы лежат только на вашем устройстве и удаляются вместе с приложением.

Какие данные обрабатываются и где

На вашем сервере Antresol

Ваш сервер — это не сервер разработчика. Им управляет его администратор (обычно вы сами). Приложение передаёт на него:

  • имя профиля и пароль при входе (пароль только проверяется и не хранится в приложении);
  • имя устройства — оно видно в списке устройств на сервере. Его можно изменить в поле «Имя устройства» при входе. На Mac по умолчанию это имя компьютера, в котором часто есть ваше имя;
  • модель устройства (например, «iPhone17,3»), версию приложения и случайный идентификатор этой установки, чтобы сервер отличал ваши устройства;
  • позицию просмотра, чтения и прослушивания, отметки «Просмотрено», «Хочу посмотреть», избранное и плейлисты;
  • запросы на копии для сохранения на устройство.

Всё это хранится на вашем сервере и подчиняется правилам его администратора. Разработчик к этим данным доступа не имеет.

На вашем устройстве

  • Токен входа для каждого профиля — в связке ключей устройства. Он доступен только этому приложению и не переносится на другие устройства.
  • Список серверов и профилей, настройки (тема чтения, качество видео, «Загружать только по Wi-Fi» и т. п.) и случайный идентификатор устройства — в настройках приложения.
  • Файлы, сохранённые «На это устройство», кэш обложек и книг, очередь ещё не отправленных позиций — в контейнере приложения. Приложение проверяет свободное место, чтобы не переполнить устройство, и показывает его в разделе «На этом устройстве».

При удалении приложения эти данные удаляются. На iPhone и iPad записи связки ключей могут пережить удаление приложения; они бесполезны без сервера и перезаписываются при следующем входе.

Обложки и описания со сторонних сайтов

Часть обложек и кадров ваш сервер указывает ссылками на общедоступные сайты: The Movie Database (TMDB), Cover Art Archive и Open Library. Приложение загружает такие изображения напрямую, без ваших данных входа. Эти сайты видят IP-адрес устройства и сам запрос изображения, как при открытии любой веб-страницы. На них действуют их собственные политики конфиденциальности.

Сеть и безопасность

  • Приложение подключается к адресу сервера, который вы ввели: в домашней сети или в интернете.
  • В домашней сети iOS и macOS могут спросить разрешение на доступ к локальной сети. Оно нужно только для связи с вашим сервером.
  • Если адрес вне дома начинается с http://, а не с https://, данные входа передаются без шифрования. Приложение об этом предупреждает. Для доступа из интернета используйте https или VPN (например, Tailscale).

Дети

Приложение не предназначено специально для детей и не собирает данных о них. Детские профили и ограничения по возрасту настраивает администратор вашего сервера.

Демо-сервер для проверки в App Store

Для проверки приложения Apple разработчик может держать демонстрационный сервер с открыто лицензированным контентом. Его журналы содержат только действия проверяющих и не используются ни для чего, кроме работы сервера.

Изменения и контакты

Если политика изменится, новая версия появится по этому же адресу с новой датой. Вопросы по конфиденциальности: через GitHub Issues.

Privacy policy (English)

Effective 26 October 2026. Antresol is an app for iPhone, iPad and Mac that browses and plays your own media library stored on a Antresol server that you (or your family's administrator) run. The developer provides no content and runs no servers your data passes through.

  • The developer collects no data. No analytics, advertising, tracking, third-party SDKs or crash reports sent to the developer.
  • The app talks only to the server address you enter. It sends it your profile sign-in, the device name, model and app version, a random installation identifier, playback/reading positions, watched and favourite marks, playlists and requests for offline copies. That server is not the developer's; its administrator controls the data.
  • Sign-in tokens are kept in the device Keychain. Settings, cached artwork and files saved for offline use stay in the app's container on the device and are removed with the app.
  • Some artwork is loaded directly from public sites your server points to (The Movie Database, Cover Art Archive, Open Library) without any sign-in data; those sites see the device's IP address, as for any web page.
  • The app is not directed at children and collects no data about them. Kid profiles and age limits are set by your server's administrator.
  • Questions: GitHub Issues. Changes are published at this address with a new date.
