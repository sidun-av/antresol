Поддержка

Lumen — плеер для вашей домашней медиатеки на iPhone, iPad и Mac. Он показывает и воспроизводит фильмы, сериалы, музыку, книги, комиксы и аудиокниги, которые хранятся на вашем собственном сервере Lumen. Приложение не предоставляет контент.

Как начать

  1. Установите сервер Lumen на компьютер или NAS дома.
  2. Откройте сервер в браузере и создайте администратора и профили для семьи.
  3. В приложении введите адрес сервера в домашней сети, например http://192.168.1.10:8420, и нажмите «Подключиться».
  4. Выберите профиль. Если у профиля есть пароль, введите его.

Вне дома

В меню профиля выберите «Адрес вне дома…» и добавьте адрес, по которому сервер открывается из интернета. Лучше всего подходит https://-адрес или VPN, например Tailscale. Приложение само выбирает доступный адрес. Для входа не из дома у профиля должен быть пароль.

Частые вопросы

«Не удалось подключиться к серверу»

Проверьте, что сервер включён и устройство в той же сети. Если iOS спрашивала доступ к локальной сети, разрешите его: Настройки › Конфиденциальность и безопасность › Локальная сеть › Lumen.

Как смотреть без сети?

На странице фильма, альбома или книги нажмите «На это устройство». Сохранённое находится в меню профиля › «На этом устройстве».

Книга не открывается

Приложение открывает EPUB, FB2, MOBI, PDF, CBZ и другие распространённые форматы. DjVu пока не поддерживается.

Как удалить данные?

Приложение не создаёт учётных записей: профили создаёт и удаляет администратор вашего сервера. Чтобы удалить данные с устройства, удалите приложение. Подробнее — в политике конфиденциальности.

In English

Lumen plays the media library stored on your own Lumen server; the app provides no content. To start: install the server at home, create the administrator and profiles in its web UI, then enter the server's home-network address (for example http://192.168.1.10:8420) in the app and choose a profile. For access away from home, add an https address or use a VPN under «Адрес вне дома…» in the profile menu. To save something for offline use, tap «На это устройство». The app creates no accounts: profiles are managed by your server's administrator. Contact: GitHub Issues.
