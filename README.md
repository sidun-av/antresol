# Antresol

Antresol is a self-hosted home media server and a player app for iPhone, iPad and Mac. It organises and plays the films, series, music, books, audiobooks and comics you keep on your own computer or NAS. No content is provided.

- Website, install guide, support and privacy policy: https://sidun-av.github.io/antresol/
- Server downloads: [Releases](https://github.com/sidun-av/antresol/releases) (Linux x86-64/ARM64, macOS)
- Docker: `ghcr.io/sidun-av/antresol-server`
- Questions and bug reports: [Issues](https://github.com/sidun-av/antresol/issues)

Only add media you have the rights to.
