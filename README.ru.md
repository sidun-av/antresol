# Antresol

[English](README.md) · **Русский**

Antresol — домашний медиасервер и приложение для iPhone, iPad и Mac. Он упорядочивает и воспроизводит фильмы, сериалы, музыку, книги, аудиокниги и комиксы, которые хранятся на вашем компьютере или NAS, — в одной библиотеке в стиле Apple. Контент не предоставляется.

- Сайт: https://sidun-av.github.io/antresol/ru/
- Установка: https://sidun-av.github.io/antresol/ru/install.html
- Поддержка: https://sidun-av.github.io/antresol/ru/support.html
- Политика конфиденциальности: https://sidun-av.github.io/antresol/ru/privacy.html

## Возможности

- **Кино и сериалы** — продолжить с того же места, «картинка в картинке», AirPlay, субтитры и звуковые дорожки, качество подстраивается под сеть.
- **Музыка** — альбомы, исполнители, плейлисты, избранное и тексты песен; воспроизведение в фоне.
- **Книги и комиксы** — EPUB, FB2, MOBI, PDF и CBZ: темы, оглавление, поиск и закладки.
- **Аудиокниги** — главы, скорость, таймер сна; позиция синхронизируется между устройствами.
- **Без сети** — сохраните фильм, альбом или книгу на устройство перед поездкой.
- **Семья** — профили с паролями и детские профили с возрастными ограничениями.
- **Веб-приложение** — та же медиатека в любом браузере, устанавливается как PWA.

## Установка сервера

Сервер — один исполняемый файл с веб-интерфейсом внутри. Нужен `ffmpeg`.

### Docker (рекомендуется)

```sh
docker run -d --name antresol --restart unless-stopped \
  -p 8420:8420 \
  -v /путь/к/config:/config \
  -v /путь/к/медиатеке:/media \
  -e VAULT_MEDIA_ROOT=/media \
  ghcr.io/sidun-av/antresol-server:latest
```

Образ для `linux/amd64` и `linux/arm64`, `ffmpeg` уже внутри.

### Готовый файл

Скачайте архив для своей системы на странице [выпусков](https://github.com/sidun-av/antresol/releases/latest) (Linux x86-64 и ARM64, macOS Apple Silicon и Intel), установите `ffmpeg` и запустите:

```sh
VAULT_DATA_DIR=~/antresol/config VAULT_MEDIA_ROOT=~/antresol ./antresol-server
```

На macOS файл пока не подписан: перед первым запуском выполните `xattr -d com.apple.quarantine antresol-server`.

## Первый запуск

1. Откройте `http://<адрес-компьютера>:8420` в браузере и создайте администратора.
2. Разложите файлы по папкам внутри `VAULT_MEDIA_ROOT`:

   | Папка | Что |
   |---|---|
   | `media/movies/` | фильмы, одна папка на фильм |
   | `media/series/` | сериалы: `Название/Season 01/…S01E01…` |
   | `media/music/` | музыка: `Исполнитель/Альбом/` |
   | `media/books/ebooks/` | книги EPUB, FB2, PDF |
   | `media/books/audiobooks/` | аудиокниги, одна папка на книгу |
   | `media/books/manga/` | комиксы и манга CBZ |

3. Создайте профили для семьи. Детским профилям задайте возрастное ограничение.
4. Установите приложение Antresol на iPhone, iPad или Mac и введите адрес сервера.

## Основные настройки

| Переменная | Что задаёт |
|---|---|
| `VAULT_DATA_DIR` | база и настройки сервера |
| `VAULT_MEDIA_ROOT` | корень медиатеки |
| `VAULT_LISTEN` | адрес и порт, по умолчанию `:8420` |
| `VAULT_PUBLIC_URL` | https-адрес сервера в интернете, если он есть |
| `VAULT_TMDB_KEY` | ключ The Movie Database для обложек и описаний (необязательно) |

Для доступа из интернета используйте https через обратный прокси или VPN (например, Tailscale).

## Конфиденциальность

Разработчик не собирает данных. Приложение связывается только с адресом сервера, который вы ввели; сервер работает на вашем оборудовании и подчиняется вам. Подробнее — в [политике конфиденциальности](https://sidun-av.github.io/antresol/ru/privacy.html).
